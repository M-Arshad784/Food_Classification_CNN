# Food Classification using CNN

## Overview

This project focuses on **food image classification using Deep Learning and Convolutional Neural Networks (CNN)**.

The model is trained to analyze food images and classify them into the food categories included in the dataset.

## Dataset

## Project Workflow

1. Collect and prepare the food image dataset.
2. Preprocess and resize the images.
3. Train a CNN-based deep learning model.
4. Evaluate the model performance.
5. Test the model on food images.
6. Predict the food category from new images.
